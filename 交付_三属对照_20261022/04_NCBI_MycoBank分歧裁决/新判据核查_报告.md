# 新判据核查报告（Diaporthe 单属试跑）

## 一、这次做了什么

把「关系类型」从**旧做法**（MycoBank 说什么就算什么）改成**按种加词比对判定**：

| 判据 | 结论 |
|---|---|
| 接受名 = Taxon name | 非异名（自己就是接受名） |
| 种加词**相同**、属名不同 | **换属 / 同一物种**（作者带括号＝新组合；无括号＝并入更早同名） |
| 种加词**词干相同**、词尾不同 | 拼写变体（如 parvae → parva） |
| 种加词**不同** | **并入别的种（真异名）** |

产物：`out_diaporthe/名字关系_新判据_v1_Diaporthe.tsv`（135 行：127 个名字，其中 8 个在 MycoBank 有两行）

## 二、结果：127 条里**没有一条是换属**

| 关系类型 | 行数 |
|---|---|
| 并入别的种（真异名） | 131 |
| 接受名就是自己（非异名） | 3 |
| 词尾不同（拼写/性别） | 1 |

**换属 = 0 条。**

## 三、与旧表比对：判据没有翻任何一条旧结论

| 旧等级 | 新类型 | 行数 |
|---|---|---|
| A 决定性 | 并入别的种 | 98 |
| B 倾向性 | 并入别的种 | 12 |
| C 待查 | 并入别的种 | 15 |
| C 待查 | 词尾不同（parvae→parva） | 1 |
| D 反向候选 | 并入别的种 | 1 |
| I 同名异物 | 并入别的种 | 5 |
| I 同名异物 | 接受名就是自己 | 3 |

**为什么不变**：这 127 条是按「NCBI 保留独立 taxon、MycoBank 并到别的名字」筛出来的，
这种情形**天然都是种加词不同**。换属问题不在这 127 条里，而在全属 1,275 个名字中（117 条换属），
属另一批数据。

## 四、判据暴露的三个问题

### 问题一（致命）：判据无法区分同名异物的两行

`longispora` / `salinicola` / `chinensis` 各有两行：一行「接受名就是自己」、一行「并入别的种」。
新判据只能如实列出两行，**无法判断 NCBI 的 taxon 对应哪一行**。
这必须靠**作者 + 模式材料**，而本地导出没有作者列。

→ 新判据**不能替代**作者核对，只能把「换属 vs 异名」分开。

### 问题二：`parvae → parva` 归为「拼写变体」是对的，但须与性别变化区分

-eae` / `parva` 词干同为 `parv`，MycoBank 状态确为 `Orthographic variant`，判「拼写变体」正确。
但**同一条规则也会把真正的性别词尾变化**（ceracea ↔ ceraceum）一并归入。
Trichoderma 的 32 条有性型属名就是这类，已单独处理为「非错」。**两者不能混为一谈。**

### 问题三：判据对「并入更早同名」这一类是**推测性**的

当种加词相同、属名不同、且接受名作者**不带括号**时，我判为「并入更早同名」。
全表这类占 39.0%（35,963 / 92,314 行）。但仅凭这 6 列**无法确证**它是：
- 后起属名并入更早的同种加词名（同一物种），或
- 两个独立物种恰好种加词相同（不同物种）

→ 要确证必须看 MycoBank 的 **Basionym / Replaced synonym** 字段（导出时未选）。

## 五、结论与建议

1. **判据可用，但对本批 127 条不产生变化**——它们本来就是真异名。
2. **换属应另立一张表**：跑全属 1,275 个名字，标出 117 条换属，说明"这不是错误"。
3. **同名异物仍须人工对作者**（4 条已用截图定案；机制上无法自动）。
4. **建议下次导出补三列**：`Authors`、`Year of effective publication`、`Basionym`。
   补齐后：同名异物可自动消歧、换属与并入更早同名可自动区分。

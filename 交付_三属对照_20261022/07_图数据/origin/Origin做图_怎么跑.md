## 一、为什么不能让我直接驱动 Origin（诊断结果）

我试了四条路，全部失败，并且找到了根因：

| 尝试 | 结果 |
|---|---|
| Python 通过 COM 连 Origin | 失败：`0x80040154 类未注册` |
| PowerShell `New-Object -ComObject` | 同上，同样报错 |
| 命令行 `Origin64.exe -rs 脚本` | 不执行（Origin 单实例，或开关不对） |
| 我写的 `.dsh-plugin` 补丁 + 重启 DSH | 配置树里已有 `mcp-origin`，但工具未进会话 |

**根因（已用注册表逐项核对）**：

```
HKLM\SOFTWARE\Classes\CLSID\{B0F21977-...}\LocalServer32
   = C:\PROGRA~1\ORIGIN~1\Origin2024\Origin64.exe     ← 这个 8.3 短路径【不存在】
真实路径
   = C:\Program Files\OriginLab\Origin2024\Origin64.exe  ← 存在
```

Windows 拿注册表里的路径去启动，找不到文件 → 报「类未注册」。
我在 `HKCU\Software\Classes` 下写了一份正确路径做覆盖，**仍未生效**，随后已把那些键删掉，机器恢复原样。

**要修它需要管理员权限**（改 HKLM）。你若想修，在「以管理员身份运行」的命令行执行：

```
"C:\Program Files\OriginLab\Origin2024\Origin64.exe" /regserver
```

这会用正确路径重写注册表。修好之后，我就能用脚本直接驱动 Origin（脚本已写好：`tools/make_origin_figs.py`）。

## 二、现在就能用的办法：把脚本粘进 Origin

**文件**：`图件生成.ogs`

**怎么跑**（三步）：

1. 打开 Origin
2. 菜单 `Window` → `Script Window`（快捷键 `Shift + Alt + 3`）
3. 用记事本打开 `图件生成.ogs`，**全选复制**，粘进 Script Window，**选中全部行**，按 `Enter`

**会看到什么**：Origin 里多出两个工作簿 `Fig2`、`Fig3`，以及对应的两张图。

**如果报错**：Script Window 会显示红字错误行号。把那几行贴给我，我改脚本——**我无法在本机验证它**（自动化通道坏了），所以第一次运行可能需要往返一次。

## 三、脚本里每一句在做什么

### 图 2 部分

```
newbook name:="Fig2" sheet:=1;   新建一个工作簿，起名 Fig2，里面建 1 个工作表
wks.ncols=4;                     这个工作表设 4 列
wks.nrows=3;                     设 3 行（三个属）
col(1)={1085,850,542};           第 1 列填三个数：CBS 在三属的号数
col(2)={286,21,36};              第 2 列：ICMP
col(3)={182,99,91};              第 3 列：CGMCC
col(4)={2080,3230,2601};         第 4 列：其他或不可核
col(1)[L]$="CBS";                [L]$ 是「长名」属性，即列的标题
plotxy iy:=(1,2:4) plot:=213;    用第 1 列做 X、第 2~4 列做 Y，画 213 号图型（堆叠柱）
```

**`213` 是什么**：Origin 自己的图型编号，取自它安装目录里的 `oPlotIDs.h`：
`#define IDM_PLOT_COLUMN_STACK 213`。同样，`201` 是散点、`254` 是带 Y 误差线的图。

### 图 3 部分

```
newbook name:="Fig3" sheet:=1;   新建 Fig3 工作簿
wks.ncols=4; wks.nrows=3;
col(1)={1,2,3};                  横轴位置（1、2、3 三个代表三个属）
col(2)={12.3,14.6,10.3};         各属的不一致率（%）
col(3)={10.8,12.6,8.2};          Wilson 95% 置信区间下限
col(4)={14.0,17.0,12.8};         置信区间上限
plotxy iy:=(1,2) plot:=201;      用第 1 列做 X、第 2 列做 Y，画散点
layer.x.from=0.5; layer.x.to=3.5; layer.x.inc=1;   横轴范围 0.5~3.5，刻度间隔 1
layer.y.from=8; layer.y.to=18; layer.y.inc=2;      纵轴范围 8~18，刻度间隔 2
draw -l {1,10.8,1,14.0};        画一条线：从 (1, 10.8) 到 (1, 14.0)，即第一个属的置信区间
draw -l {2,12.6,2,17.0};        第二个属
draw -l {3,8.2,3,12.8};         第三个属
draw -l {0.5,12.6,3.5,12.6};    一条横线在 12.6%，即合计率的参考线
```

**为什么用 `draw -l` 画置信区间，而不用 Origin 的误差线功能**：
Wilson 置信区间**上下不对称**（率不在区间正中），Origin 的误差线默认按 ±对称处理，
用它会把区间画歪。画竖线能如实反映上下限。

## 四、注意事项

1. **横轴现在显示 1 / 2 / 3，不是属名**。执行完后双击横轴，把刻度标签手动改成
   `Colletotrichum` / `Trichoderma` / `Diaporthe`（或告诉我你的 Origin 版本，我补上自动改标签的语句）。
2. **导出图像**：脚本最后一行 `expGraph` 被注释掉了（以 `//` 开头）。
   先确认图对了，再去掉 `//` 并把 `path:=` 改成你要的目录。
3. **图 2 的四列顺序**：CBS / ICMP / CGMCC / 其他。若想改颜色，双击柱子 → 逐条设。

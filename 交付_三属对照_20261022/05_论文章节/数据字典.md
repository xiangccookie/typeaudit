# 数据字典 · 每份派生表的每一列是什么意思

> 配套文件：`补充表清单.md`（哪份文件对应论文哪一段）。
> 本文件只解释**列的含义**，不重复论文里的方法叙述。

---

## 通用约定

| 约定 | 含义 |
|---|---|
| **问题标记** | 写在方括号里，如 `CBS 127945 [号不存在]`；多个标记用 `;` 分隔；`[—]` 表示无标记 |
| **非错类标记** | `异名（非错）`、`基名属`——看着不符，实际指同一物种 |
| **错值类标记** | `号不存在`、`号有误（应为 X）`、`CBS 记为别种`、`书写错误（应为 X）`、`未知机构代码` |
| **不确定类标记** | `疑似非机构编号`、`未核` 等——无法判定对错 |
| **`(strain)` 前缀** | 该号来自 GenBank 的 `/strain` 字段，是实验室编号，无机构前缀，**不在核对范围内** |
| **空值** | 空字符串表示「该字段没有值」，不是「值为 0」 |

## `<属>_三列表.tsv`

**一句话**：每个种「登记了哪些菌株号 / 哪些模式菌号」，以及每个号的问题标记。

| 列 | 含义 | 取值示例 |
|---|---|---|
| 种名 | 规范双名 | `Colletotrichum acerbum` |
| 菌株号（含问题） | 该种全部菌株号，`｜` 分隔 | `CBS 128530 [—] ｜ (strain) CBS 128530 [—]` |
| 模式菌（含问题） | 声明为模式材料的号 | `CBS 128530 [—]` |

---

## `<属>_发现汇总.tsv`

**一句话**：全部发现逐条列出，是图 3、图 4 与所有分类计数的底表。

| 列 | 含义 | 取值示例 |
|---|---|---|
| 序号 | 行号 | `1` |
| 层级 | 属哪一层审计 | `号级` / `名字级` / `种级` / `序列级` |
| 类别 | 发现的具体类别 | `号不存在` / `疑似非机构编号` / `申报模式而机构无记录` |
| 对象 | 出问题的号或名 | `CBS 147945` |
| 发现 | 一行描述 | `该号在 CBS 目录中查无` |
| 归类 | 四类归属 | `不一致` / `不确定` / `非错` / `种级分歧` |
| 来源 | 由哪一步产出 | `机构目录` / `MycoBank` / `反向审计` |
| 证据 | 判定依据 | 目录返回内容或查询方式 |

---

## `四方核验.tsv`

**一句话**：每个种在四个库里的说法并排，用于看「同一株菌四处四种说法」。

| 列 | 含义 |
|---|---|
| 种 | 规范双名 |
| MycoBank接受名 | MycoBank 认为该名现在该叫什么 |
| NCBI_taxid | NCBI 分类库的 taxon 编号 |
| NCBI类型材料号 | NCBI Taxonomy 登记的类型材料编号 |
| CBS类型号 | CBS 目录里该种的类型号 |
| CGMCC该名号 | CGMCC 目录中该名下登记的号 |
| CGMCC模式号 | CGMCC 目录中标注为模式的号 |
| 矛盾数 / 待核数 / 提示数 | 三个计数（对应「确定冲突 / 无法判断 / 需注意」） |
| 矛盾明细 / 待核明细 / 名称分歧 | 上述计数的逐条内容 |

## `序列轴_同号多名.tsv`

**一句话**：同一个保藏号，在 GenBank 里被标成了几个不同的种。

| 列 | 含义 | 取值示例 |
|---|---|---|
| 种 | 我们审计时该号所属的种 | `Colletotrichum siamense` |
| 号 | 保藏号 | `CBS 125378` |
| GenBank里出现的种名 | 该号在各记录里被标成的种，`×次数` | `Colletotrichum siamense×12 / Colletotrichum hymenocallidis×2` |
| 判定 | `两个不同的种` / `同一个种 + 种下单元` | — |
| 记录数 | 命中记录数 | `14` |
| 登录号 | GenBank 登录号，逗号分隔 | `MH876058,MH864620` |

---

## `反向审计_号不存在.tsv`

**一句话**：被判「号不存在」的每一条，回查 GenBank 的结果。

| 列 | 含义 |
|---|---|
| 号 | 被判不存在的号 |
| 声明种 | 声称使用该号的种 |
| GenBank命中数 | 有多少条记录引用了该号 |
| GenBank里的种名 | 这些记录各自的种名 |
| 判定 | `机构未收录`（有引用且种名相符）/ `支持不存在`（无引用）/ `待核`（仅命中基因组级大记录） |

---

## `<属>_类型号反查.tsv`

**一句话**：该种**声明为模式材料**的号，在 GenBank 里出现在哪些物种名下。

| 列 | 含义 | 取值示例 |
|---|---|---|
| 种 | 声明该号属于本种 | `Colletotrichum siamense` |
| 类型号 | 声明为模式材料的号 | `CBS 125378` |
| 记录数 | GenBank 命中记录数 | `14` |
| GenBank里的物种 | 各物种及出现次数 | `siamense×12 / hymenocallidis×2` |
| 判定 | `一致` / `记为别的种` / `两个及以上物种` / `未检出记录` | — |

⚠️ **口径提醒**：`两个及以上物种` 的原始计数含大量假象（`UNVERIFIED:` 前缀、专利序列、非本属记录）。
论文用的是**过滤后**的数（只保留「Colletotrichum + 合法种加词」），过滤前后分别约 313 条与 24 条，详见 `_汇总.json` 与论文正文。

## `<属>_基因组层.tsv`

**一句话**：每个基因组组装来自哪一株菌、有没有模式材料声明、NCBI 有没有判它归属错。

| 列 | 含义 | 取值示例 |
|---|---|---|
| 属 / 种 | 该种 | `Colletotrichum coccodes` |
| 记录物种名 | 提交者写的物种名（可含菌株后缀） | `Colletotrichum coccodes` |
| assembly | NCBI 组装名 | `ASM224977v1` |
| biosample | BioSample 号 | `SAMN03761679` |
| strain | 该组装的菌株号 | `NJ-RT1` |
| culture_collection | 机构保藏号（若有） | `CBS:127945` |
| type_material | **模式材料声明**（非空 = 该组装声称来自模式菌株） | `culture from epitype of Colletotrichum graminicola` |
| genome_notes | NCBI 官方备注；含 `unverified source organism` = **官方判定分类学归属错误** | `unverified source organism` |

⚠️ **边界**：`type_material` 为空 **不等于** 一定不是模式菌株——可能只是提交者没填。论文按「未声明即非模式」计，因此 67.2% 是**上限估计**。

## `<属>_受信菌株表.tsv`

**一句话**：经检查、与外部目录一致、没有任何问题标记的号。

| 列 | 含义 |
|---|---|
| 种名 | 该号所属的种 |
| 模式菌号 | 该种下受信的模式菌号（`;` 分隔） |
| 菌株号 | 该种下受信的一般菌株号 |
| 模式号说明 / 菌株号说明 | 为什么算受信（空 = 无标记；有内容 = 仅非错类标记，如「异名（非错）」） |

⚠️ **「受信」只表示「号与外部目录一致」**：
- **不**表示这株菌真是模式菌株；
- **不**表示序列属于该种；
- 只覆盖 CBS / ICMP / CGMCC 三家，其余机构的号一律不进表（**把「没检查」当「受信」是错的**）。

---

## `<属>_覆盖声明.tsv`

**一句话**：哪些种因为 GenBank 记录太多，本次只扫描了一部分。

| 列 | 含义 | 取值示例 |
|---|---|---|
| 种名 | 受影响的种 | `Colletotrichum falcatum` |
| 覆盖情况 | 总记录数与实扫数 | `覆盖不全：该种 GenBank 记录 2132 条，本次仅扫 1500 条` |

# 发布 v1.2.0（GitHub Release → Zenodo 自动出新 DOI）

## 现在的状态

```
提交 c288199  已推送 main
tag  v1.2.0   已推送（提交号 c288199）
上一个归档版本 DOI：10.5281/zenodo.23575367（对应 v1.0.9，数字是修正前的）
概念 DOI（永远指向最新）：10.5281/zenodo.23574863
```

**我不能替你发 Release** —— 本机没有 `gh` 命令行、也没有个人访问令牌，
而 SSH 只能推送代码，不能创建 Release。所以下面三步需要你在网页上点。

---

## 三步操作（约 2 分钟）

1. 打开 https://github.com/xiangccookie/typeaudit/releases/new
2. 顶部 **Choose a tag** 选 **v1.2.0**（已经推上去了，下拉里能选到）
   - Release title 填：`v1.2.0 — 三属审计定稿（153 条分歧全部核查、41 条名字变体、三张图）`
   - 描述用下面那段（可直接复制）
3. 点 **Publish release**

发布后 Zenodo 会自动抓取（通常几分钟），在 https://zenodo.org/account/settings/github/
可以看到新 DOI。拿到新 DOI 后告诉我，我把论文里那段「版本对应说明」改成指向它。

```
三属（Colletotrichum / Trichoderma / Diaporthe，1,360 种）公共基因组元数据审计定稿。

## 主要数字
- 号级单元格 11,103；可核 3,192（28.7%）

本版及 v1.1.0 起为剔除后（非错 205 / 矛盾 153 / 分歧 153）。详见 CHANGELOG.md。
```

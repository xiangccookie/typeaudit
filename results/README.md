# results/ —— 论文结论对应的原始表

本目录收录论文所引用的**全部结果表**（41 个文件，2,161,885 字节）。
每个数字都能在这里追到来源。论文正文的「方法与结果」见项目文档（不随仓库发布）。

## 口径说明（重要）

1. **两种单位不可混用**：`三列表` 是**单元格**口径（同一个号在「菌株号」和「模式菌」两列各算一次）；
   `发现汇总` 是**条目**口径（同一（种, 号）只算一次）。例如「NCBI 声明为模式号而机构无此记录」
   单元格 241 条、条目 194 条——**论文用 194**（此处指「申报模式但机构无记录」，
   与「异名/独立种分歧」无关；后者已由 194 修正为 169，因剔除 25 条拼写变体）。
2. **不全是「错误」**：多数判定是**两份记录相互矛盾**（不一致），不是经独立验证的错误。
   全文用「不一致率」而非「错误率」，理由见论文方法。
3. **同名异物**：`biguttulata` / `longispora` / `salinicola` / `chinensis` 四例涉及「同名异物」，
   须按**命名人 + 模式材料**对号，判据与依据见裁决表。

## 如何重新生成

```bash
python tools/chain_genus.py --genus <属名> --chunk 40
```

该命令依次完成：取种清单 → 分块审计 → 合并 → 补全链（四方核验 / 反向审计 / 序列轴 / 分类库 / 汇总）。
依赖的第三方数据（CBS 目录、MycoBank 导出、NCBI 缓存）不入库，获取方式见根目录 README 的「数据准备」。
